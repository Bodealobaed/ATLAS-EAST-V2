# ATLAS EAST — تحديث الاسم والتنقل الأفقي

- أصبح الاسم المعروض **ATLAS EAST** بالأحرف الكبيرة، مع الحفاظ على المجهر الملون.
- أصبح اختيار **الرئيسية / مساحة العمل** أفقيًا في الشريط الجانبي.
- تبويبات التحليل العلمي التسعة تبقى أفقية وقابلة للتمرير عند ضيق الشاشة.
- لم تتغير آليات رفع الملفات أو التحليل أو المحاكاة أو الكتب أو التقارير.
- انقل **محتويات هذا المجلد** إلى جذر مستودع GitHub، ثم Commit.
- لا ترفع مفتاح API إلى GitHub؛ استخدم Streamlit Secrets.
- اختبارات محلية: `python tests/test_regressions.py` و `python tests/test_brand_navigation.py`.
- لم يُختبر النشر المباشر على Streamlit Cloud أو كل مسارات API.
