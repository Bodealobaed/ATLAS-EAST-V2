# تحديث ATLAS V2.6 — الصفحة التعريفية

- صفحة رئيسية تعريفية تظهر عند فتح التطبيق، بدون طلب تحميل ملف.
- زر واضح للانتقال إلى مساحة العمل التي تضم جميع أدوات النسخة V2.5 دون تغيير.
- اختيار الصفحة من القائمة الجانبية؛ لا تُحذف البيانات عند التنقل.
- ترجمة الصفحة التعريفية وأزرار التنقل بالكامل للعربية والألمانية والإنجليزية.
- إبقاء التبويبات الأفقية في مساحة العمل لتجنب كسر الوظائف القائمة؛ يمكن تغيير ترتيبها لاحقًا.

## النشر
ارفع **محتويات** هذا المجلد إلى جذر مستودع GitHub الخاص بالتطبيق، بما في ذلك app.py، ولا ترفع مفاتيح API. إعداد Secrets الحالي يبقى كما هو.

تم فحص الصياغة البرمجية واختبارات الانحدار المحلية؛ لم يُختبر النشر المباشر على Streamlit Cloud أو اتصال OpenAI.
