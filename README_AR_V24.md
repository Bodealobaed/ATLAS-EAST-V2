# ATLAS Research Intelligence V2.4 — إصلاح إنشاء الكتب وتوسيع التقرير

## التثبيت
ارفع **محتويات** هذا المجلد إلى جذر مستودع GitHub الحالي، واستبدل الملفات الموجودة، ثم Commit. لا ترفع ملف `.streamlit/secrets.toml` أو أي مفتاح API.

## التغييرات
- لم يعد توليد الكتاب يتوقف تلقائيًا عند 30 جزءًا؛ الحد الفني الجديد 500 جزء، مع عداد تقدم واستئناف الأجزاء التي اكتملت **داخل جلسة Streamlit نفسها** عند إعادة المحاولة. الانقطاع أو إعادة تشغيل الخادم قد يفقد بيانات الجلسة؛ لا توجد طابور مهام دائم.
- تصدير كتاب A5 مع غلاف أمامي وصفحة عنوان وفهرس تلقائي وفصول وخاتمة وملحقات الصور والجداول وغلاف خلفي. ملف غلاف مطبعة احترافي منفصل مع الكعب وbleed ليس ضمن هذا الإصدار.
- التقرير البحثي يحتوي على ملحقات صور وجداول مقتبسة من الأصل (حد 24 من كل نوع)، وشعار مجهر ملون في التذييل. لا يضمن عدد صفحات معينًا أو امتثالًا تلقائيًا لشروط مجلة محددة.
- إضافة نص علمي تفسيري للسيناريو الخطي الافتراضي، **وليس** محاكاة علمية مستخرجة تلقائيًا من المشروع.
- قبول PNG/JPEG/TIFF في معاينة الصور الطبية، إلى جانب DICOM/NIfTI. المعاينة وقناع العتبة ليسا تشخيصًا أو تقسيمًا تشريحيًا معتمدًا؛ لا ترسل بيانات مرضى معرّفة.
- شعار المجهر نفسه وألوان الواجهة، وشعار صغير داخل PDF، مع عبارة إنجليزية موجزة في الواجهة.

## حدود مهمة
الكتاب الطويل قد يتطلب عشرات طلبات OpenAI API وتكلفة ووقتًا ملحوظين. إعادة الصياغة تحتاج مراجعة كاملة للأرقام والمراجع وحقوق النشر. الاستئناف متاح فقط ما دامت حالة جلسة Streamlit محفوظة. قد تُوقف Streamlit Cloud عملية طويلة؛ يحتاج الحل الإنتاجي إلى عامل مهام منفصل وتخزين دائم. لا يمكن الادعاء بأن هذه النسخة تؤدي تشخيصًا طبيًا أو محاكاة متعددة الفيزياء أو تستخرج بيانات المنحنيات تلقائيًا.

## الاختبارات
نجح اختبار الانحدار السابق وفحص تركيب Python، واختبار 81 جزءًا، وتوليد PDF للكتاب والتقرير ببيانات اصطناعية. لم يُجرَ اختبار نشر فعلي على Streamlit Cloud أو طلبات OpenAI الحقيقية.
